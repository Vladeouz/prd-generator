## Keputusan yang diambil sendiri

- **`Chip` memakai input radio atau checkbox asli, bukan tombol `aria-pressed` seperti di `design.md`.**
  - Alasannya: di form, radio dan checkbox sudah memberi navigasi keyboard (panah dalam grup), status terpilih untuk pembaca layar, dan perilaku form tanpa state tambahan.
  - Dengan cara ini test lama yang memeriksa `type="checkbox"` dan `checked=""` tetap lulus tanpa diubah.
  - Tampilannya sama dengan mockup.
  - Baris `Chip` di `design.md` sudah disesuaikan setelah disetujui user (sesudah merge T-020).
- **Satu tahap per layar (`?tahap=N`)**, sesuai mockup ("TAHAP 2 / 8" dan panel samping khusus tahap). Akibatnya test lama `ProjectView › menampilkan bagian tahap 2 dan tahap 3` diubah: dulu merender keduanya di satu halaman, sekarang memeriksa `stage="2"` dan `stage="3"`. Isi pemeriksaannya tetap: kedua bagian bisa ditampilkan.
- **Dua atribut diurutkan ulang** (`data-testid` ditulis terakhir) di status job dan "Tahap terakhir selesai". Test lama mencocokkan `data-testid="…">teks`. Hanya urutan atribut yang berubah, test-nya tidak.
- **Teks lama dipertahankan meski berbeda dari mockup**, karena perilakunya berbeda atau test lama memakainya:
  - "Buat proyek" (mockup: "Mulai klarifikasi"): membuat proyek tidak langsung menjalankan klarifikasi;
  - "0/4000 karakter" (mockup: "0 / 4000");
  - "Simpan jawaban" (mockup: "Simpan dan lanjut"): menyimpan tidak berpindah tahap;
  - token ditulis "x input · y output" (mockup: "64,6 rb token").
- **Warna mode terang** yang tidak disebut `design.md` diturunkan sendiri dan diperiksa kontrasnya (rumus WCAG):
  - `--surface-raised` #FFFFFF, `--border-subtle` #E4E8ED, `--text-secondary` #2F3640, `--text-faint` #646D79;
  - status: success #126B33, high #A93A0B, medium #8A5A00, low #1D4ED8.
  - Hasil kontras di atas latar alfa 14%: success 5.05, high 4.83, medium 4.60, low 5.07. Teks redup: 4.93 di latar, 5.24 di surface.
  - Catatan untuk T-021: teks aksen #3D5FD9 di atas `accent-soft` di latar halaman 4.27 (di surface 4.52). Badge proyek berada di surface.
- **Tidak ada token "danger"** di `design.md`, jadi error dan tombol "Hapus proyek" memakai `--severity-high`.
- **Header ada di setiap view** (`HomeView`, `ProjectView`, `SettingsView`), bukan di `layout.tsx`, karena breadcrumb dan token berbeda per halaman. Status template dibaca server lewat `templateStatus()` setiap kali halaman dibuka.
- **Breakpoint**: tiga kolom mulai `xl` (1280 px); di `lg`, stepper di kiri dan panel di bawah konten; di bawah itu satu kolom.
