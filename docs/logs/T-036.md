## Keputusan yang diambil sendiri

- **`git ls-files`, bukan menelusuri folder.** Hanya file yang di-commit (sesuai `template_commit`, NFR-04), tanpa `node_modules`, `.dart_tool`, build, atau file lokal. Repo template memang wajib Git (commit dibaca sejak T-006).
- **File notes dikenali dari segmen path**, bukan dari daftar file di bagian konvensi "Menghapus fitur contoh notes". Lebih sederhana, dan di template saat ini hasilnya sama: tidak ada file notes yang tersisa, dan tidak ada file lain yang terbuang.
- **Aturan duplikat hanya untuk tiga akhiran** (`.route.ts`, `.route.test.ts`, `-repository.ts`). Use case, domain, dan test integration per area wajar bertambah di folder yang sama, sedangkan satu route dan satu repository per fitur adalah pola template. Bila suatu saat fitur template butuh route kedua, aturan ini perlu dilonggarkan.
- **Pemeriksaan daftar file di awal job hanya bila template valid.** Template tidak valid tetap dilaporkan 7a dengan pesan konvensinya ("Repo template belum valid …"), sehingga test dan pesan yang ada tidak berubah.
- **Aturan level test diperiksa per kriteria utuh** (perintah unit test + `METHOD /v1/…` + kode status, bukan dokumen OpenAPI). Heuristik yang lebih luas, misalnya semua kriteria unit test yang menyebut log, akan menolak test logger template yang sah.
