## Status

## Ringkasan

- **Penyebab temuan T-018** (temuan 1, 7, 9, 12 di `docs/logs/T-018.md`, branch `test/t-018-uji-nyata`):
  - prompt 7a v2 sendiri meminta "fase 0 berisi skema dan migrasi tabel proyek", sehingga T-001 proyek uji membuat 8 tabel sekaligus, sementara task fitur juga mendaftarkan tabelnya;
  - konvensi `stage7a` tidak membawa aturan kontrak template ("jalankan `contract:generate` setiap kali route atau skema Zod berubah, lalu commit bersama perubahan route"), dan `contract` tersedia sebagai layer. Hasilnya task kontrak terpisah, sehingga `pnpm check` task API gagal (agent T-002 proyek uji harus melanggar `files`);
  - "boleh kosong" untuk `depends_on` di prompt membuat 26 dari 34 task tanpa dependensi.
- **Konvensi `stage7a`** kini juga membawa `## Database` dan `## Kontrak dan client Dart` (`src/template/sections.ts`).
- **Prompt 7a versi 3**:
  - `depends_on` wajib untuk setiap task kecuali T-001, dengan alasannya;
  - task `db` wajib punya `tables`; setiap tabel dibuat tepat satu task, kecuali tabel template (`{{templateTables}}`);
  - urutan per fitur: tabel milik fitur → API → Flutter; tidak membuat semua tabel di fase 0;
  - kontrak di-generate di task yang mengubah route atau skema Zod, tanpa task kontrak terpisah;
  - daftar layer dari `PLAN_LAYERS` (tanpa `contract`).
- **Validator 7a** (`validateStage7a`) menolak:
  - task selain yang pertama tanpa `depends_on`;
  - layer `contract`, dengan pesan yang menyebut `pnpm contract:generate`;
  - task `db` tanpa `tables`, dan `tables` di layer selain `db`;
  - tabel yang tidak ada di PRD, tabel yang dibuat lebih dari satu task, dan tabel PRD yang tidak dibuat (kecuali `TEMPLATE_TABLES` = `users`). Nama tabel dibandingkan tanpa membedakan huruf besar-kecil, karena erDiagram gym memakai huruf besar.
- **`task-rules.ts`**: `PLAN_LAYERS` dan `TEMPLATE_TABLES`. `TASK_LAYERS` tetap memuat `contract` agar TASKS.md lama (fixture verifikasi T-014) tetap terbaca validator TASKS.md.
- **Fixture**:
  - output nyata uji T-018 disalin apa adanya dari database lokal ke `test/fixtures/claude/verification/t018-*` (tahap 4, tahap 5, review 2 percobaan 1, 7a, 7b fase 0–3, PRD v2), dengan `fixture_source` dan error validator lama. Dipakai juga T-030 dan T-031;
  - `derived/stage7a-gym.json` dibangun ulang: task db pertama ("Skema Drizzle dan migrasi awal") mendapat semua tabel erDiagram selain `users`, task db lain `[]`. Fixture gym sudah memenuhi aturan dependensi dan tanpa task `contract`.
