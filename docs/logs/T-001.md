## Keputusan yang diambil sendiri

1. **TypeScript 7.0.2** (versi `latest`, sama dengan template). `next typegen`, `tsc --noEmit`, dan `next build` berjalan normal.
2. **`@types/node` 24.19.2**, bukan `latest` (26.x), agar tipe sesuai runtime Node 24.
3. **Script unit test bernama `test:unit`**, bukan `test`, mengikuti aturan template soal perintah bawaan pnpm.
4. **`pnpm typecheck` = `next typegen && tsc --noEmit`**: `next typegen` membuat `next-env.d.ts` dan tipe rute tanpa perlu `next dev`/`next build` lebih dulu. Run pertama `next typegen` menambah `esModuleInterop: true` ke `tsconfig.json` (wajib menurut Next); sudah ikut di-commit sehingga tidak berubah lagi.
5. **`agentRules: false` di `next.config.ts`**: `next dev` 16.4 membuat `AGENTS.md` di root yang berisi instruksi agar agent meng-commit file itu. Aturan agent di repo ini hanya di `CLAUDE.md`, jadi fitur dimatikan; Next kemudian menghapus file itu sendiri. `CLAUDE.md` tidak tersentuh.
6. **`TEMPLATE_DIR` dari variabel lingkungan proses menang atas `.env`**, sama dengan urutan Next.js memuat env, sehingga perilaku `prereq` sama dengan aplikasi.
7. **`TEMPLATE_DIR` harus path absolut** di `prereq` (searah NFR-01 untuk path).
8. **Tailwind CSS 4 dipasang di T-001** untuk halaman awal, agar task UI berikutnya tidak perlu menyentuh konfigurasi build.
9. **Biome mengecualikan `docs/reference/`** agar bahan rujukan tidak diformat ulang.

Usulan untuk `docs/conventions.md`: semua keputusan di atas sudah dicatat di sana (bagian Versi, Script, TypeScript dan Next.js, Lint).
