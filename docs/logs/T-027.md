## Keputusan yang diambil sendiri

- **`StageJob` di samping `StageDefinition`**, bukan satu definisi besar. Setiap pemanggilan tetap memakai `runStage`, sehingga pencatatan, percobaan ulang, dan progres sama dengan tahap lain tanpa duplikasi.
- **Menjalankan ulang setelah lengkap = membuat ulang semuanya.** Tanpa itu, tombol "Jalankan ulang" tidak berbuat apa-apa setelah TASKS ada. Menjalankan ulang setelah gagal hanya mengulang fase yang belum valid, sesuai kriteria.
- **Format 7b**: `files`, `done_when` (array), dan `manual` (`criterion` + `steps`). Bagian baku (`pnpm check`, persiapan, Flutter web) dilarang di output AI dan ditambahkan `composeTasks`. Dengan begitu bagian baku selalu sama dan tidak bisa salah tulis.
- **Potongan PRD 7b memuat bagian 4 bila ada task `db`.** Task skema merujuk tabel, bukan FR tertentu. Tanpa bagian 4, `files` dan *done when* migrasi akan menebak nama tabel.
- **Konvensi di awal prompt 7b**, agar awalannya sama untuk setiap fase dan bisa dibaca dari cache. Data aplikasi tidak memisahkan token cache, jadi penghematannya tidak terukur di log ini.
- **Aturan prompt tahap 7 lama dipindah ke prompt 7a v2.** Prompt 7a v1 belum pernah dipanggil dengan `claude` sungguhan.
- **`attemptNote` hanya untuk percobaan terakhir yang ditolak.** Di tahap berlangkah, keterangan dari fase sebelumnya akan menyesatkan.
- **Validasi akhir `validateTasks` tetap dipakai** (aturan T-014) sebagai pengaman, walaupun bagian baku dibuat kode.

## Kendala

- Regex fase di runner palsu awalnya tidak cocok dengan kalimat prompt ("… di aplikasi PRD Generator, untuk fase 2"), sehingga e2e gagal. Diperbaiki, dan ditambah test pemilihan fase.
- Durasi verifikasi manual tepat di batas NFR-06 (301 dtk untuk 5 fase dan 37 task).
- TASKS.md nyata 111 KB (rata-rata ±3 KB per task). Ukurannya tidak dibatasi FR-08/NFR-06, dan `docs/TASKS.md` dibaca agent per task, bukan sekaligus. Bila perlu mempercepat, usulan task: batasi `done_when` 7b (misalnya ≤ 6 kriteria) atau jalankan fase paralel. Keduanya mengubah keputusan, jadi butuh persetujuan user.
