## Keputusan yang diambil sendiri

1. **`projects.current_stage`** memakai nilai tahap (`stage2`…`stage7`, `review2`) ditambah `export`, karena PRD tidak menyebut nilainya. Proyek baru dimulai di `stage2` ("tahap klarifikasi produk siap dijalankan", FR-01).
2. **`decisions.category` tanpa CHECK.** Kategori review pertama sudah tetap (`REVIEW_CATEGORIES` di `e2e-gym.mjs`), tetapi kategori review kedua (T-013) dan keputusan profil (`D-01`) belum ditentukan. CHECK di sini akan menebak daftar yang belum ada. Validasi kategori dilakukan Zod per tahap. **Usulan:** bila daftar lengkap sudah pasti di T-013, tambahkan CHECK lewat migrasi.
3. **Constraint tambahan** yang tidak tertulis di PRD tetapi mengikuti maknanya: unique `documents (project_id, kind, version)` ("version naik setiap kali dibuat ulang"), unique `feature_choices (project_id, feature_code)`, `attempt >= 1`, `version >= 1`, dan kolom 0/1 untuk `is_current`/`accepted`. `answers` sengaja tidak diberi unique karena cara penyimpanan ulang jawaban baru diputuskan di T-008.
4. **Lokasi database utama tetap `data/prd-generator.db`** (relatif ke folder proyek), tanpa variabel `.env`, karena itu yang paling sederhana.
5. **Migrasi dijalankan oleh `openDatabase()`** setiap kali database dibuka, bukan lewat script terpisah. Migrasi idempoten, dan aplikasi tidak bisa berjalan dengan skema lama.
6. **`getDb()` melempar error saat `NODE_ENV=test`**, sehingga "tidak menyentuh database utama" dijamin oleh kode, bukan hanya oleh kebiasaan test.
7. **Biome mengecualikan `drizzle/meta`**, sama dengan template. Migrasi di-generate ulang dari nol setelahnya, karena `pnpm format` sempat memformat ulang snapshot sebelum pengecualian ditambahkan.

## Kendala

- **`better-sqlite3` 13 dan kriteria `allowBuilds`.** Versi 13 membawa binary prebuilt (`prebuilds/win32-x64.node`) yang dimuat lebih dulu. Build script-nya hanya `node-gyp rebuild` bawaan, dan bila diizinkan, `pnpm install` gagal (`gyp ERR! find Python`) karena mesin ini tidak punya Python dan compiler C++. Atas persetujuan user, `better-sqlite3: false` dipakai, dan kriteria T-003 diubah dari "diizinkan lewat `allowBuilds`" menjadi "diatur eksplisit lewat `allowBuilds`".
- **drizzle-kit 0.31.11 di Windows** menggabungkan path `--out` absolut dengan cwd (`D:\dev\prd-generator\C:\Users\…`), gagal dengan `ENOENT`, tetapi tetap keluar dengan exit 0. Test memakai path relatif di `node_modules/.cache` dan memeriksa pesan "No schema changes", bukan hanya exit code.
