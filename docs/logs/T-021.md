### Langkah verifikasi manual

Perkiraan waktu: ±15 menit. Tidak memakai kuota Claude (runner palsu).

1. **Persiapan `.env`.** Tambahkan tiga baris ini (contoh juga ada di `.env.example`); `TEMPLATE_DIR` tetap seperti sekarang:

   ```
   CLAUDE_COMMAND=node D:\dev\prd-generator\test\helpers\fake-claude-cli.mjs
   FAKE_CLAUDE_MODE=flow
   FAKE_CLAUDE_DELAY_MS=5000
   ```

2. **Server.** Hentikan `pnpm dev` yang sedang berjalan (Ctrl+C), lalu jalankan lagi `pnpm dev` agar `.env` terbaca. Buka `http://127.0.0.1:3000` di Chrome.
3. **Beranda.** Buat proyek baru, misalnya nama "Uji T-021" dan ide "Aplikasi membership untuk sebuah gym". Isi idenya bebas; runner palsu selalu menjawab dengan fixture gym.
4. **Tahap 2–4.** Di setiap tahap tekan tombol jalankan. Banner "… sedang berjalan" tampil sekitar 5 detik, lalu hasilnya muncul. Simpan jawaban tanpa mengubah apa pun (pakai default). Di tahap 4 biarkan fitur rekomendasi tidak dicentang, lalu simpan.
5. **Tahap 5 (review kritis).** Jalankan, lalu bandingkan dengan `docs/design/mockups/Review.dc.html`: ringkasan keparahan, kartu temuan (kode, keparahan, kategori, kotak BUKTI, opsi radio dengan label Rekomendasi), buku keputusan di kanan, bilah bawah "Berikutnya: PRD, sekitar 5–10 menit". Simpan keputusan.
6. **Tahap 6 (PRD).** Tekan "Jalankan penulisan prd": panel konfirmasi muncul dan fokus ada di "Ya, jalankan". Tekan Escape: panel tertutup dan fokus kembali ke tombol. Jalankan lagi lalu pilih "Ya, jalankan". Banner menampilkan waktu berjalan, perkiraan, dan bilah progres. Setelah selesai, bandingkan dengan `Prd.dc.html`: daftar isi di kiri (klik "8 Assumptions & Decisions" untuk melompat), dokumen di tengah dengan keterangan "Disusun aplikasi" di bawah bagian 8, panel Dokumen, Pemakaian, dan Ekspor di kanan. Jalankan review kedua dan simpan keputusannya **tanpa** memilih opsi "Mengubah PRD".
7. **Tahap 7 (TASKS)** lalu **tahap 8 (Ekspor)**: jalankan TASKS, lalu klik "Tulis ke folder proyek" di panel Ekspor. Unduh PRD.md dan TASKS.md. Bila mau, tulis ke folder proyek turunan template (tidak wajib untuk task ini).
8. **Keyboard.** Muat ulang halaman, lalu tekan Tab sekali: tautan "Lewati ke konten utama" muncul di kiri atas. Tekan Tab beberapa kali: setiap elemen yang mendapat fokus punya cincin biru yang terlihat. Di kartu proyek, "Hapus proyek" membuka panel konfirmasi merah (jangan konfirmasi; tekan Batal).
9. **Keadaan error.** Buka `http://127.0.0.1:3000/projects/tidak-ada`: layar "Halaman tidak ditemukan" dengan tautan kembali.
10. **Tema dan 390 px.** Klik tombol tema dan ulangi pemeriksaan sekilas langkah 5–7 dalam mode terang. Lalu di DevTools (F12 → Toggle device toolbar) set lebar 390 px: beranda, tahap 5, 6, 7, dan 8 terbaca tanpa geser ke samping, di kedua tema.
11. **Selesai.** Hapus atau beri tanda `#` pada tiga baris `.env` dari langkah 1, lalu jalankan ulang `pnpm dev` agar aplikasi kembali memakai Claude Code sungguhan.

Yang perlu dikonfirmasi: tampilan review dan PRD sesuai mockup, langkah 8–10 berjalan seperti di atas, atau daftar hal yang perlu diperbaiki.

## Keputusan yang diambil sendiri

- **Aksen mode terang `#3D5FD9` → `#3858D3`.** Dengan nilai lama, teks aksen di atas latar aksen 12% (badge "IDE → PRD → TASKS", nomor tahap aktif di stepper) hanya 4,39:1. Nilai baru 4,76:1, dan tombol utama naik dari 5,47 ke 5,99. `design.md` diperbarui dengan nilai baru dan alasannya. Warna mode gelap tidak berubah.
- **Stepper tetap ada di layar PRD.** Mockup PRD mengganti stepper dengan daftar isi dan bilah progres segmen di header. Daftar isi kini di atas stepper (sticky, mulai `lg`), dan stepper tetap di bawahnya sebagai navigasi antartahap. Bilah segmen di header tidak dibuat karena isinya sama dengan stepper.
- **Panel Ekspor di layar PRD berisi unduhan dan tautan ke layar ekspor**, bukan form tulis ke folder yang nonaktif seperti di mockup. Form-nya tetap satu, di layar ekspor (tahap 8), agar tidak ada dua form dengan state berbeda.
- **Perkiraan di banner dan tombol tahap 6–7 memakai angka yang sama dengan konfirmasi** (`bannerEstimate`: rata-rata pemanggilan atau angka uji). Teks tetap "sekitar 5–10 menit" bila perkiraan tidak tersedia.
- **Halaman tidak ditemukan berstatus HTTP 200** saat dibuka di browser, karena `loading.tsx` membuat halaman di-stream sebelum `notFound()` dipanggil (perilaku Next.js). Isinya tetap layar "Halaman tidak ditemukan". Untuk aplikasi lokal satu pengguna ini tidak berdampak; API tetap mengembalikan 404.
- **Kontras diperiksa dengan pemeriksa sendiri berbasis rumus WCAG 2.x** (`test/helpers/contrast.ts`) yang membaca token langsung dari `globals.css`, bukan alat luar, agar ikut dijalankan `pnpm check` dan perubahan token yang menurunkan kontras langsung ketahuan. Rumusnya diuji dengan nilai yang sudah dikenal (hitam/putih 21:1, `#767676`/putih 4,54:1).
- **Runner palsu mode `flow`** mengenali tahap dari kalimat pertama prompt, sehingga tidak perlu mengubah kode aplikasi atau prompt. Pemetaannya sama dengan `GYM_FIXTURES`.

Usulan untuk `docs/conventions.md` sudah ditambahkan di bagian UI dan Claude Code (keadaan layar, `ConfirmPanel`, keyboard, kontras, pembaca dokumen, banner job, mode `flow`).
