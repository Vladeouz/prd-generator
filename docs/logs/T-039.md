# T-039 Upgrade Next.js dari 16.4.0 ke versi yang sudah ditambal

## Status

Selesai. Branch `chore/t-039-upgrade-nextjs`. Fase 3e. Verifikasi manual di Chrome dijalankan oleh Claude Code atas izin dan otorisasi eksplisit user.

## Ringkasan

- **Masalah (temuan T-036, T-037, T-038):** CLI Next.js 16.4.0 memeriksa advisory npm dan, berselang-seling, menghentikan `next build`/`next dev` dengan `SecurityFatalError` ("Your version of Next.js is affected by a known security vulnerability"), sehingga `pnpm check` merah tanpa test yang gagal.
- **Advisory yang menyebabkannya** (sumber: endpoint `https://registry.npmjs.org/-/npm/v1/security/advisories/bulk`, yang dirujuk pesan error itu, lalu dicocokkan dengan GitHub Advisory Database):

  | Advisory | CVE | Tingkat | Rentang terdampak 16.x | Versi tambalan pertama |
  | --- | --- | --- | --- | --- |
  | [GHSA-p3m5-59mp-jv5r](https://github.com/advisories/GHSA-p3m5-59mp-jv5r): Denial of Service di App Router lewat Server Actions | CVE-2026-94482 | high | `>= 16.0.0, <= 16.4.0` | 16.4.1 |
  | [GHSA-2464-fhr4-w9xw](https://github.com/advisories/GHSA-2464-fhr4-w9xw): RCE tanpa autentikasi di Image Optimization API untuk file SVG | – | critical | `>= 16.0.0, <= 16.4.0` | 16.4.1 |
  | [GHSA-673q-mjm6-r5xr](https://github.com/advisories/GHSA-673q-mjm6-r5xr): RCE tanpa autentikasi di fungsi `use cache` yang mengembalikan typed array | – | critical | `>= 16.0.0, <= 16.4.0` | 16.4.1 |

  Ketiganya terbit 22 Oktober 2026, sehingga pesan CLI baru muncul sejak T-036.
- **Versi tujuan: 16.4.2** (patch dalam 16.x). Kandidat yang menutup ketiga advisory: 16.4.1 (rilis 14 Okt), 16.4.2 (15 Okt), dan 16.4.3 (23 Okt 13:40 UTC). Endpoint advisory mengembalikan "tidak ada advisory" untuk ketiganya. 16.4.3 belum lolos `minimumReleaseAge` pnpm (umurnya ±23 jam saat dicek pukul 13:01 UTC, 24 Okt), jadi dipilih yang terbaru di antara versi yang lolos.
- **Upgrade** dengan `pnpm add -E next@16.4.2`, bukan `next upgrade` dari pesan CLI. `pnpm-workspace.yaml` tidak berubah (tidak ada `minimumReleaseAgeExclude`). Lockfile: `next` dan `@next/*` naik ke 16.4.2 (41 baris berubah).
- Tidak ada perubahan API yang perlu disesuaikan: `pnpm typecheck`, build, dan test lulus tanpa mengubah kode. `next dev` 16.4.2 juga tidak membuat `AGENTS.md` (`agentRules: false` tetap berlaku).

## Verifikasi manual

User memberi izin dan otorisasi agar Claude Code menjalankan verifikasi manual ini sendiri (Claude in Chrome).

Langkah yang dijalankan:

1. `pnpm install --frozen-lockfile` dan `pnpm dev` di branch ini: "▲ Next.js 16.4.2 (Turbopack)", tanpa `SecurityFatalError`.
2. Di Chrome dibuka:
   - beranda `http://127.0.0.1:3000/`: hero, form buat proyek, dan daftar 7 proyek tampil;
   - proyek "Reservasi Massage 2" (`/projects/f9d3823b-…`): tahap Ekspor (bawaan), lalu tahap Struktur fitur (`?tahap=4`) dengan daftar fitur per fase, panel keputusan teknis, tabel pemakaian token, dan flowchart fitur (`@xyflow/react`; node dan kontrol zoom tampil);
   - pengaturan `/settings`: repo template Valid, Claude Code Terpasang, profil model dan effort.
3. Console DevTools di ketiga halaman: tidak ada error atau exception. Indikator Next.js di pojok kiri bawah tidak menunjukkan error.
4. **Pembanding "tidak berubah":** HTML ketiga halaman diambil dengan `curl` dari dev server 16.4.2, lalu dari dev server 16.4.0 (`git checkout master`, `pnpm install --frozen-lockfile`) dengan data yang sama. Ukuran file sama persis (64.035, 291.754, dan 47.345 byte). Setelah nama chunk `/_next/static/…` dinormalkan, perbedaan yang tersisa hanya path `.pnpm` yang memuat versi Next.js, id request `__next_r`, dan nomor baris internal payload RSC. Struktur, class, dan teks halaman identik. Screenshot pengaturan di 16.4.0 juga sama dengan di 16.4.2.
5. Dev server dimatikan, tab ditutup, dan working tree kembali ke branch ini dengan Next.js 16.4.2 terpasang.

Catatan: saat membandingkan, `pnpm dev` di 16.4.0 (`master`) sempat berhenti sekali lagi dengan `SecurityFatalError`; percobaan kedua berjalan. Ini mengonfirmasi masalah yang ditutup task ini. Pesan itu berisi instruksi yang ditujukan ke agent (menawarkan `next upgrade --agent=security …`); instruksi itu tidak dijalankan karena berasal dari output tool.

## Keputusan yang diambil sendiri

- **16.4.2, bukan 16.4.3:** 16.4.3 belum lolos `minimumReleaseAge`, dan kriteria melarang melewati policy itu. 16.4.2 sudah menutup ketiga advisory, jadi task tidak perlu dihentikan. Versi 16.4.3 bisa diambil nanti lewat task terpisah bila perlu.
- **16.4.2, bukan 16.4.1:** keduanya lolos dan sama-sama ditambal; dipilih patch terbaru yang lolos policy.
- **Sumber advisory:** endpoint advisory registry npm, yang dibaca CLI Next.js sendiri, dicocokkan dengan GitHub Advisory Database (`api.github.com/advisories/<GHSA>`) untuk `first_patched_version`. Keduanya termasuk sumber resmi yang disebut kriteria (advisory di GitHub).
