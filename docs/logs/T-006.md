## Keputusan yang diambil sendiri

1. **Template harus berupa repo Git.** Commit yang tidak terbaca membuat template tidak valid, karena NFR-04 meminta setiap dokumen bisa ditelusuri ke commit template. `pnpm prereq` (T-001) masih menganggapnya OK dengan keterangan "commit tidak terbaca". **Usulan:** samakan `prereq` di task berikutnya yang menyentuhnya.
2. **Commit ditampilkan penuh (40 karakter)**, sama dengan baris `commit` dari `git log -1`, agar mudah dibandingkan dan sesuai yang akan disimpan di `projects.template_commit`.
3. **Respons `GET /api/settings` persis sesuai kontrak** (`templateDir`, `templateCommit`, `claudeAvailable`). Daftar masalah dan versi Claude hanya ada di halaman, yang membaca `getSettings()` langsung sebagai server component.
4. **Ketersediaan Claude Code diperiksa dengan `claude --version`** setiap kali halaman dibuka (sekitar 1 detik, tanpa kuota). Kalau `claude` tidak tersedia, itu tidak masuk daftar masalah template, tetapi ditampilkan terpisah.
5. **Tampilan dipisah ke `SettingsView`** agar bisa di-test dengan `renderToStaticMarkup` tanpa menambah Testing Library atau jsdom.
6. **Belum ada tautan ke `/settings` dari halaman utama**, karena `src/app/page.tsx` milik T-007. **Usulan:** T-007 menambahkan tautan, dan peringatan bila template bermasalah.
