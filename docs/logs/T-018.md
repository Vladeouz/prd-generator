## Temuan dan usulan task

1. **`depends_on` kosong lolos validator 7a.** 26 dari 34 task tidak punya `depends_on`, termasuk semua task mulai T-010 (misalnya T-011 kontrak terapis tanpa T-009, dan T-017 reservasi tanpa T-014). Agent tetap mengambil task berurutan, jadi urutannya tidak rusak, tetapi dependensinya hilang. *Usulan task:* validator 7a menolak task tanpa `depends_on` selain task pertama (atau minimal memberi peringatan), dan prompt 7a menegaskannya.
2. **Keputusan review menyebut fase yang tidak ada.** RV-01 dan RV-02 merekomendasikan "Tambah fitur … di fase 4", dan PRD menulis "R-01 … fase 4 (RV-01)". Fase tahap 4 hanya 0–3, jadi task R-01/R-03 diletakkan 7a di fase 3 (sesuai validator). Akibatnya PRD dan TASKS tidak sejalan. *Usulan task:* prompt tahap 5 hanya boleh menyebut fase yang ada (atau aplikasi memvalidasi nomor fase di opsi temuan), atau 7a boleh menambah fase baru yang tercatat.
3. **Percobaan ulang review kedua karena `passed_checks`.** Percobaan pertama ditolak karena `passed_checks` berisi kalimat bebas, bukan nilai yang dikenal validator. Biayanya satu pemanggilan tambahan ($0,135, 32 dtk). *Usulan task:* prompt review 2 menyebut daftar nilai `passed_checks` yang diizinkan secara eksplisit, atau validator menganggap nilai tak dikenal sebagai peringatan.
4. **Percobaan ulang tahap 4 karena `phases` kosong.** Kemungkinan output dipotong atau model lupa field. Percobaan ulang berhasil. Dicatat saja; belum perlu task kecuali terulang.
5. **Perkiraan durasi di konfirmasi terlalu tinggi.** Konfirmasi tahap 6 menyebut "sekitar 8 menit" (rata-rata 3 pemanggilan sebelumnya), padahal hasilnya 65 dtk. Penulisan ulang PRD menyebut "sekitar 6 menit" dan selesai 63 dtk. Rata-rata ikut menghitung run lama sebelum efisiensi T-023/T-025. *Usulan task:* `stageEstimate` hanya memakai run dengan versi prompt terbaru (atau N run terakhir).
6. **`files` 7b berisi keterangan di dalam backtick**, misalnya `` `apps/api/src/db/schema.ts (tabel services, …)` ``. Path tidak bisa disalin apa adanya. *Usulan task:* validator 7b menolak `files` yang bukan path (ada spasi atau tanda kurung), dengan keterangan dipisah di luar path.
7. **T-001 membuat skema semua fitur sekaligus** (services sampai notifications) di fase 0. Ini bertentangan dengan "satu fitur per layer" dan membuat task pertama besar. Belum tentu salah (constraint anti-bentrok lintas tabel), tetapi perlu ditinjau setelah sesi Claude Code. Usulan menunggu hasil sesi.
8. **Dari T-028:** "Pas ke layar" pada graf besar terlalu kecil untuk dibaca, dan panel detail ada di bawah graf.
