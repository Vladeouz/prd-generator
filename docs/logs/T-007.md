- Domain proyek `src/projects/projects.ts`:
  - `createProject` (tahap awal `stage2`);
  - `listProjects` (terbaru dulu, dengan tahap terakhir yang selesai dan total token);

- UI:
  - halaman utama dengan tautan **Pengaturan** ke `/settings`, form proyek baru (penghitung karakter ide, error per field), dan daftar proyek (tahap terakhir selesai, token, waktu dibuat);

## Keputusan yang diambil sendiri

1. **Nama proyek wajib, 1–100 karakter.** PRD hanya membatasi ide. Nama dan ide di-trim sebelum disimpan, dan ide yang hanya berisi spasi dianggap kosong.
2. **Batas 4000 dihitung dengan `String.length`** (unit UTF-16), sama dengan `maxLength` di textarea, agar form dan server selalu sepakat.
3. **`GET /api/projects` mengembalikan `ProjectSummary`** (Project + `lastCompletedStage` + `totalTokens`), karena FR-01 meminta daftar menampilkan keduanya. Kontrak PRD menulis `Project[]`; field-nya hanya ditambah, tidak ada yang diubah.
4. **"Tahap terakhir yang selesai"** = tahap paling akhir menurut urutan alur (`stage2` … `stage6`, `review2`, `stage7`) yang punya `stage_runs` `succeeded` dengan `is_current = 1`.
5. **Total token = jumlah `input_tokens` + `output_tokens` semua `stage_runs` proyek, termasuk percobaan yang gagal**, karena semuanya memakai kuota. Ditampilkan terpisah, input dan output.
6. **`ProjectDetail`** berisi `completedStages`, `answers` (dengan `value` sudah di-parse dari `value_json`), `featureChoices`, `decisions`, `documents: { prd, tasks }` (versi terbaru masing-masing, atau `null`), dan `activeJob`.
7. **Pemeriksaan job aktif dan penghapusan dalam satu transaksi**, sehingga job tidak bisa dimulai di antara keduanya.
8. **Halaman membaca domain langsung sebagai server component**, bukan `fetch` ke API sendiri. API tetap tersedia untuk komponen klien dan sesuai kontrak.
9. **Interaksi klien (klik, navigasi) tidak diuji otomatis di T-007**, karena Testing Library dan jsdom tidak ada di stack. Interaksi diperiksa di browser sungguhan, dan otomatisasinya menjadi bagian Playwright di T-017.
